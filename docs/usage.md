# Using SurfCoder Regional Surf Report

## Quick start

Choose a region and forecast location, or enter coastal coordinates and select Use custom coordinates. Choose units and a day. Save a location only on your device, or download CSV. Forecast requests send the chosen coordinates to marine-api.open-meteo.com and api.open-meteo.com; no geolocation permission or API key is used. Data errors remain visible and are never replaced by invented live conditions.

## Supported workflow

1. Twelve regions, including 46 named North Carolina beaches, plus custom coordinates.
2. Seven-day live wave, swell and wind forecasts.
3. Local-time day selection, metric/imperial units, saved location and CSV.

## Validation and troubleshooting

Run the commands in the README. Invalid inputs produce explicit errors rather than silently changing the requested operation. Browser audio requires a user gesture; microphone apps require HTTPS or localhost and permission. For file tools, supply supported input formats and writable output directories.

## Limitations

Offshore grid forecasts do not resolve every beach break, tide, current, hazard, or local wind effect. Check conditions locally and follow lifeguard guidance.

Tests use synthetic fixtures. These tests do not certify hardware compatibility, real-world forecast quality, trained-model accuracy, or production suitability for every input.

North Carolina now has 46 named choices, including Indian Beach and North Topsail Beach. Location groups run from the northern Outer Banks to the Brunswick Islands.
